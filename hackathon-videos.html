Why a key, and how to get one (free, about 5 minutes)
Google Drive won't let a web page download its files directly. With a Drive API key, the playlist pages can pre-download Drive videos that are shared as “Anyone with the link”. The check also shows which teams haven't shared their file. Without a key, Drive videos stream live during judging.
  1. Open console.cloud.google.com, sign in with any Google account and create a project (any name).
  2. APIs & Services → Library: search for Google Drive API and click Enable.
  3. APIs & Services → Credentials → Create credentials → API key. Copy the key and paste it above.
  4. Recommended: edit the key, set API restrictions → Restrict key → Google Drive API, and save.
The key is saved inside the playlist files, but it can only read files that are already public. Delete it in the console after the event.
